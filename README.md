# Ispitni projekat za predmet Dizajn i razvoj softvera
Tema projekta jeste kreiranje informacionog sistema za potrebe ketering preduzeca.

## Tech Stack
C# .NET WPF (MVVM arhitektura)
SQLite

### Instalacija
1. Aplikaciju je potrebno preuzeti sa udaljenog repozitorijuma (git clone)
2. Potrebno je pokrenuti migracije za kreiranje baze podataka (Package Manager Console - komanda: Update-Database)
3. Build + Run aplikacije
